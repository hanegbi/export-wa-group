# Privacy policy for WhatsApp Chat Export

WhatsApp Chat Export does not collect, transmit, sell or share any data.

The extension reads the messages of the WhatsApp Web chat you have open, only when you press Export, and only to build the text file you asked for. That text is kept in your browser's session storage so you can download or copy it, and it is erased when you close the browser. Files you download are saved to your own computer.

The extension makes no network requests, uses no analytics and has no server.

Questions: open an issue at https://github.com/hanegbi/export-wa-group/issues

This extension is an independent project. It is not affiliated with, endorsed by or sponsored by WhatsApp or Meta.
