Store upload kit

Everything for the Chrome Web Store listing of WhatsApp Chat Export 1.0.0: the package to upload, the text for each form field, and every image variant.

Files to upload

Built by python store/package.py into store/upload/.

  1. Open the Chrome Web Store Developer Dashboard and choose New item.
  2. Upload whatsapp-chat-export-1.0.0.zip.
  3. Fill in Store listing and Privacy with the text below, and add the images you picked.
  4. Submit for review.

Store listing text

The name and summary come from manifest.json automatically. Copy the rest into the matching fields.

Privacy tab text

The dashboard asks for a reason for each permission. Answer "No" to remote code, and tick no data-collection boxes: nothing is sent anywhere.

Images

Click an image to open it at full size. The files are in store/images/, all 24-bit PNG with no transparency.
